# Planar Quadrotor

A C++ simulation of planar quadrotor dynamics with a discrete linear-quadratic regulator (LQR) and an SDL-based visualizer.

## Requirements

- A C++ compiler
- Eigen 3
- SDL2 development libraries

## Build and run

The repository contains C++ source files but no build-system file. Configure the source files in your IDE or build setup, include Eigen, and link SDL2. The simulation entry point is `simulate.cpp`.
